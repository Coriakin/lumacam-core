# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Email the maintainer privately with:

- A short description of the impact
- Steps to reproduce (or a proof-of-concept) if you can share one safely
- Affected versions or commit range, if known

Allow reasonable time for a fix before public disclosure.

## Scope

This repository contains client-side RTSP and media handling libraries. Reports about **camera firmware**, **network misconfiguration**, or **third-party services** are usually out of scope for this codebase unless they involve a defect in these libraries themselves.
